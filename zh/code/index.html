工具代码

这些 Python 小工具用来生成本站、查公共交通、排一天的顺序、给每个地方找图，按 MIT 许可发布（Transitous 数据条款要求使用它 API 的项目开源）。行程数据不在这里。

  • build_site.py：从行程文件生成静态网站，发布前扫描产物里有没有隐私信息。
  • check.py：检查行程文件（天页、地点库、预订）的格式，只报不改。
  • images.py：从维基百科、Wikimedia Commons 和 Openverse 给地点找候选图，记下选定那张的许可证。
  • plan_day.py：给定起点、最晚回到哪和候选地点，按真实时刻表排一天的顺序，给推荐、备选和每个被舍候选的原因。
  • privacy.py：替换或拦下名单里的词，给邮箱打码，扫描生成的网站。
  • transit.py：从 Transitous 查站、查班次、查整天时刻表。
  • tripdata.py：读行程数据（地点、天页、要提前做的、决定、图片来源），网站和 agent 共用这组函数。
  • LICENSE

把这种做法重做成 AI 助手可用服务的开源项目是 tripwright，见关于本页。
